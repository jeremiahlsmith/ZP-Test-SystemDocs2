The Insurance Billing API is a REST API that uses JSON request and response bodies. All requests go to `https://api.example-billing.com/v1`.

## Authentication

Send your API key in the `Authorization` header:

```http
Authorization: Bearer YOUR_API_KEY
```

Keys are created in **Settings > API keys**. Use sandbox keys for testing. They work only against the sandbox environment.

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/claims` | Create a claim from a completed encounter |
| `GET` | `/claims/{claimId}` | Retrieve a claim and its current status |
| `POST` | `/claims/{claimId}/submit` | Scrub and submit a claim to the payer |
| `POST` | `/eligibility/checks` | Verify a patient's coverage and benefits |
| `GET` | `/remittances/{remittanceId}` | Retrieve a parsed 835 remittance and its payments |
| `GET` | `/denials` | List open denials, filterable by payer and reason code |

## Create a claim

`POST /claims`

```bash
curl https://api.example-billing.com/v1/claims \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "patientId": "pat_10482",
    "payerId": "payer_bcbs_il",
    "encounterDate": "2026-11-02",
    "renderingProviderNpi": "1234567893",
    "diagnosisCodes": ["J06.9"],
    "lines": [
      { "cptCode": "99213", "units": 1, "chargeAmount": 125.00 }
    ]
  }'
```

**Response** `201 Created`

```json
{
  "claimId": "clm_8f21a9",
  "status": "draft",
  "totalCharge": 125.00,
  "createdAt": "2026-11-02T14:22:08Z"
}
```

## Check eligibility

`POST /eligibility/checks`

```json
{
  "patientId": "pat_10482",
  "payerId": "payer_bcbs_il",
  "serviceDate": "2026-11-16"
}
```

**Response** `200 OK`

```json
{
  "checkId": "elg_44c0d2",
  "coverageActive": true,
  "copay": 25.00,
  "deductibleRemaining": 380.00,
  "checkedAt": "2026-11-16T15:01:44Z"
}
```

## Errors

Errors return a JSON object with a stable `code` and a human-readable `message`.

```json
{
  "code": "claim_validation_failed",
  "message": "Diagnosis code J06.9 is not valid for CPT 99213 with this payer."
}
```

| HTTP status | Meaning |
| --- | --- |
| `400` | Request is malformed or fails validation |
| `401` | API key is missing or invalid |
| `404` | Resource not found |
| `409` | Resource is in a state that does not allow the action |
| `429` | Rate limit exceeded. Retry after the `Retry-After` interval. |
| `500` | Server error. Retry with exponential backoff. |

## Rate limits

The default limit is 100 requests per minute per API key. Contact support to raise it.
