Reporting gives billing managers a view of claim performance across all locations, payers, and providers. Reports refresh every hour and can be exported as CSV or PDF.

## Standard reports

| Report | What it shows | Typical use |
| --- | --- | --- |
| Claims summary | Claims submitted, accepted, rejected, and paid by month | Monthly billing review |
| Payment posting | Payments and adjustments posted by payer and date range | Reconcile remittance deposits |
| Denial trends | Denial volume and rate by reason code and payer | Find recurring root causes |
| Days in A/R | Open balances grouped by age (0-30, 31-60, 61-90, 90+ days) | Prioritize collections |
| Eligibility activity | Verifications run, active versus inactive results, and response times | Measure front-desk workflow |

## Run a report

1. Open **Reports** from the main navigation.
2. Select a report from the list.
3. Set the **Date range**, **Location**, and **Payer** filters.
4. Select **Run**. Results appear in the table below the filters.
5. Select **Export** to download the results.

<Note>
  Reports include only claims that have been submitted to the clearinghouse. Draft claims appear in the **Claim submission** queue, not in reports.
</Note>

## Schedule a report

To receive a report automatically:

1. Open the report and select **Schedule**.
2. Choose a frequency (daily, weekly, or monthly) and a delivery time.
3. Add one or more recipient email addresses.
4. Select **Save schedule**.

Scheduled reports are sent as a CSV attachment. You can pause or delete a schedule at any time from **Reports > Scheduled**.

## Permissions

| Role | View reports | Run and export | Create schedules |
| --- | --- | --- | --- |
| Billing manager | Yes | Yes | Yes |
| Billing specialist | Yes | Yes | No |
| Front-desk staff | Eligibility activity only | No | No |
